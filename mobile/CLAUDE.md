# Hook Spot Mobile — Claude Guidelines

## Tech Stack
- **Expo 54** bare workflow + **React Native 0.81.5**
- **@rnmapbox/maps** — Mapbox Maps SDK for iOS (raw native, not web GL)
- **Zustand v5** — same stores as web (`store/` is a symlink to `../src/store/`)
- **@supabase/supabase-js** — same client as web (`lib/supabase.js`)
- **react-native-reanimated** + **@gorhom/bottom-sheet** — replaces Radix UI
- **expo-image-picker** — replaces DropOverlay/file input
- **expo-location** — GPS for photo tagging
- **React Navigation** or **Expo Router** — TBD in Phase 6

## Key Files
- **Entry**: `index.js` → `App.js`
- **Screens**: `app/` (to be created per phase)
- **Components**: `components/` (RN-specific; no CSS Modules — use `StyleSheet`)
- **Shared**: `store/` and `lib/` are symlinks → `../src/store/` and `../src/lib/`
- **Config**: `app.json` — bundle ID `com.hookspot.app`, scheme `hookspot`
- **Native**: `ios/HookSpot.xcodeproj` — generated by `expo prebuild`

## Architecture
- No `<div>`, no CSS Modules — use `<View>`, `<Text>`, `StyleSheet.create()`
- No Radix UI — use `@gorhom/bottom-sheet` for sheets, RN `Modal` for dialogs
- No `iconoir-react` — use `@expo/vector-icons` or inline SVGs
- Map markers: `ShapeSource` + `SymbolLayer` (GeoJSON, same data shape as web)
- `flyToPhoto` → `Camera.flyTo()` on the `@rnmapbox/maps` Camera ref
- Supabase auth deep link: `hookspot://auth` (configured in `app.json` scheme)

## Building
- Requires real Mapbox secret token (sk.eyJ...) with `DOWNLOADS:READ` scope
- Prebuild: `RNMAPBOX_MAPS_DOWNLOAD_TOKEN=sk.eyJ... npx expo prebuild --platform ios --clean`
- Run simulator: `npx expo run:ios`
- EAS build for TestFlight: `eas build --platform ios --profile preview`

## Standards
- Keep screens thin — logic in stores or lib functions
- Zustand selectors: `usePhotoStore(s => s.photos)` — no whole-store subscriptions (same as web)
- Pure lib files (`groupByTime.js`, `formatters.js`, etc.) work unchanged via symlink
